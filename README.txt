JAI DOWNS — COMP-101 E-PORTFOLIO

This is a six-page static website:
1. index.html — Homepage
2. claim.html — Central learning claim and synthesis statement
3. artifact1.html — Assignment 1 introduction and paste area
4. artifact2.html — Assignment 2 introduction and paste area
5. artifact3.html — Assignment 3 introduction and paste area
6. reflection.html — Research trail, feedback, usability, revision log, and AI use statement

PREVIEW
- Unzip this folder.
- Open index.html in a web browser.
- Use the navigation at the top to visit all six pages.

ADDING YOUR ASSIGNMENTS AND NOTES
- On each artifact page, click the large white text area and paste your complete assignment.
- The reflection page has separate editable areas for each required reflection topic.
- Text saves automatically in the same browser on the same device. Browser storage is not a substitute for keeping a backup copy.
- Replace the bracketed prompts in each artifact introduction with your own details.
- Review and personalize the central claim and synthesis using examples from your actual course work.

PUBLISHING A PUBLIC URL
This package is a working local website, but it is not hosted online yet. To get a shareable portfolio URL, upload the unzipped folder to a static hosting service such as Netlify Drop or GitHub Pages. Keep all six HTML files, styles.css, and portfolio.js together in the same folder. Upload the folder contents (not just index.html). Follow your instructor's requirements for public access and submission.

IMPORTANT
The assignments themselves have not been provided, so their spaces are intentionally blank. Add your own complete work before submitting. Make sure your AI use statement matches your actual use and your instructor's policy.
