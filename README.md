# Jai Downs — Comp-101 E-Portfolio

A six-page static portfolio website for Comp-101.

## Pages
- `index.html` — Homepage
- `claim.html` — Central learning claim and synthesis statement
- `artifact1.html` — Assignment 1 introduction and assignment area
- `artifact2.html` — Assignment 2 introduction and assignment area
- `artifact3.html` — Assignment 3 introduction and assignment area
- `reflection.html` — Process statement, research trail, feedback, usability notes, revision log, and AI use statement

## Publish with GitHub Pages

1. Sign in to [GitHub](https://github.com/) or create an account.
2. Create a new **public** repository named `jai-downs-portfolio`.
3. Upload the contents of this folder to the repository's root. Make sure `index.html`, `styles.css`, and `portfolio.js` are at the top level, not inside another nested folder.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes. GitHub will display your published URL in the Pages section. It should look like `https://YOUR-GITHUB-USERNAME.github.io/jai-downs-portfolio/`.

## Before submitting
- Replace the prompts in each artifact introduction with your own details.
- Paste your complete assignments into the three artifact pages.
- Complete the reflection sections and make sure the AI use statement accurately describes your process.
- Keep a backup copy of your assignment text. The editable areas save in the browser on the device where you enter them; browser storage is not included in GitHub uploads.
- Test the published link in a private/incognito browser window to confirm it is publicly accessible.
